# betterGitGUI

一个简单的 .NET 4.8.1 C# WinForms 程序，模仿 Git GUI 的窗体布局，内置常用一键 Git 功能，调用计算机中的 Git 来实现功能。

## 功能

- **仓库管理**：打开已有仓库、初始化新仓库（自动定位 git.exe）
- **文件状态**：左侧「未暂存」/ 右侧「已暂存」双栏列表，状态着色（M 修改、D 删除、?? 未跟踪）
- **一键操作**：
  - 暂存所选 / 暂存全部、取消暂存所选 / 取消暂存全部（双击列表项也可暂存/取消暂存）
  - 提交（提交信息通过 stdin 传入，避免引号/转义问题）
  - 修改上次提交（amend）
  - 丢弃所选改动、硬重置到 HEAD
- **远程**：Fetch / Pull / Push
- **分支**：检出分支、新建分支、删除已合并分支
- **查看**：提交日志（graph 视图，最近 200 条）
- **输出面板**：完整显示每条 git 命令、退出码与耗时

## 依赖

- 本机安装 Git（自动探测 PATH 等）
- .NET Framework 4.8.1

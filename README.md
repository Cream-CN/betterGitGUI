# betterGitGUI

一个简单的 .NET 4.8.1 C# WinForms 程序，模仿 Git GUI 的窗体布局，内置常用一键 Git 功能，调用计算机中的 Git 来实现功能。

## 功能

- **仓库管理**：打开已有仓库、初始化新仓库（自动定位 git.exe，含注册表探测）；「最近打开」菜单记住最近 10 个仓库，下次启动自动打开上次的仓库
- **文件状态**：左侧「未暂存」/ 右侧「已暂存」双栏列表，状态着色（M 修改、D 删除、?? 未跟踪、冲突红色加粗）
- **差异面板**：选中任一文件即刻显示该文件的 unified diff（未暂存看工作区、已暂存看暂存区、未跟踪文件显示全部内容），按行着色
  - 右键差异面板可以 **按块（hunk）暂存 / 取消暂存 / 丢弃**，不必整个文件一起走
  - 常用操作：暂存整个文件、取消暂存整个文件、复制差异、复制文件路径
- **一键操作**：
  - 暂存所选 / 暂存全部、取消暂存所选 / 取消暂存全部（双击列表项也可暂存/取消暂存）
  - 提交（提交信息通过临时文件传入，避免引号/转义与 BOM 问题）；暂存区为空时会提醒
  - 修改上次提交（amend）；「上次信息」一键把上次提交说明填进提交框
  - **撤销上次提交**：`reset --soft HEAD~1`，提交退回暂存区，改动不丢
  - 丢弃所选改动、硬重置到 HEAD
- **储藏（Stash）**：把当前改动存进储藏、储藏列表、弹出 (pop)、应用 (apply)、删除 (drop)，列表右侧直接预览储藏内容
- **远程**：Fetch / Pull / Push；**一键同步**（fetch + pull --rebase + push，任一步失败就停下）
- **修改远程地址（SSH ⇄ HTTPS）**：`远程` 菜单里打开，列出 `git remote -v` 的 fetch 行并识别每个远程当前是 SSH 还是 HTTPS 写法，默认把选项落在「另一种」上，预览转换结果后一键 `git remote set-url`
  - 支持 `git@host:owner/repo.git`、`ssh://user@host:port/path`、`https://host/path` 互相转换；非 22 端口用 `ssh://` 形式保留端口
  - 转成 HTTPS 时丢弃地址里的账号密码；本地路径 / `file://` / UNC 地址会被拒绝并提示
  - 没有远程时可直接「添加远程...」
- **GitHub 面板（依赖 GitHub CLI `gh`）**：`GitHub` 菜单或工具栏 `GitHub` 按钮打开
  - PR：列表、详情（分支、增删行数、评审结论、CI 检查项、描述）、新建 PR（可指定目标分支/草稿）、检出到本地、浏览器打开、squash 合并、关闭
  - Issue：列表、详情（标签、最近 5 条评论）、新建、浏览器打开、关闭
  - 面板顶部显示 `gh` 版本、登录账号、当前仓库；未安装 `gh` 时给出安装提示，并可「指定 gh.exe」手动选路径（路径会记住）
  - 「登录 / 授权」调用 `gh auth login --web`；「在浏览器打开仓库」优先用 `gh repo view --web`，没有 gh 就从 origin 地址推出网页地址
- **同步状态**：状态栏显示当前分支、上游分支以及 ↑N 待推送 / ↓N 待拉取
- **分支**：检出分支、新建分支、删除已合并分支；**中止合并 / 中止变基**
- **冲突处理**：冲突文件单独标出，右键可「用我的版本 / 用对方版本 / 标记为已解决」
- **提交历史**：独立窗口，左侧提交列表（含全部分支，排除 stash），右上该次提交改动的文件，右下选中文件的 diff
- **刷绿（贡献图）**：
  - 日期在 GitHub 贡献图样式的方格图上点选（单击切换、按住拖动可连续选、支持今天/最近 7/30/90 天快捷选择）
  - 三种生成方式：按文件拆分、指定提交数拆分、只刷绿（直接生成空提交，不动工作区）
  - 提交在所选日期上平均分配（余数随机落到某几天），具体时刻在上班时间内随机抖动，且不会落在未来
  - 生成预览后，方格颜色深浅就是执行后贡献图的样子，预览表里每条提交信息都能单独修改
- **效率细节**：状态栏过滤框按路径筛选两个列表；F5 刷新；Ctrl+Enter 提交；Ctrl+Shift+A 全部暂存；切回窗口自动刷新；右键菜单可在资源管理器中定位、用默认程序打开文件、复制路径
- **输出面板**：完整显示每条 git 命令、退出码与耗时

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| F5 | 刷新状态与分支信息 |
| Ctrl+Enter | 提交 |
| Ctrl+Shift+A | 全部暂存 |

## 依赖

- 本机安装 Git（自动探测 PATH、常见安装目录与注册表）
- .NET Framework 4.8.1
- 可选：GitHub CLI（`gh`），用于「GitHub 面板」。安装：`winget install GitHub.cli`，或到 https://cli.github.com 下载；装好后在面板里点「登录 / 授权」，也可以在命令行执行 `gh auth login`
